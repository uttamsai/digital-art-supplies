# Digital Art Supplies — CS351 Project 1

A client-only React SPA storefront for **Digital Art Supplies**, a fictitious retailer of
drawing tablets — built with Vite, React, Bootstrap 5, and client-side
JavaScript. No Node/Express backend and no database are used — all product
data lives in `src/data/products.json` and the shopping cart lives in React
state.

The catalog covers three kinds of drawing hardware from real manufacturers
(Wacom, Huion, XP-Pen, GAOMON, Xencelabs): screenless **pen tablets**, **pen
displays** (built-in screen, tethered to a computer), and **standalone
tablets** (built-in Android, no computer needed). Digital Art Supplies itself is a
made-up storefront, similar to how a real electronics retailer sells
third-party manufacturers' products — it is not affiliated with or endorsed
by any of the brands listed.

## Tech stack

- React 19 (function components + hooks)
- Vite 8 (build tool / dev server)
- React Router v7 (`HashRouter`, so client-side routes work on a plain static
  file host like Google Cloud Storage without any server-side rewrite rules)
- Bootstrap 5 (grid, navbar, forms, buttons, pagination) + a small amount of
  custom CSS in `src/styles/index.css`

## Project structure

```
src/
  main.jsx              # app entry point, imports Bootstrap CSS/JS
  App.jsx               # routes + the cartItems[] state (lifted here)
  data/
    products.json       # 28 products across 3 categories
  components/
    NavBar.jsx           # persistent nav + identity logo + cart badge
    Footer.jsx
    ProductList.jsx       # .map()s a product array into ProductCards
    ProductCard.jsx        # one product summary, links to its detail page
    Pagination.jsx
    Cart.jsx               # .map()s cartItems[] into CartItems + totals
    CartItem.jsx             # one cart line + qty controls + remove
  views/
    HomeView.jsx
    ShopView.jsx            # ProductList + search/category filter + paging
    ProductDetailView.jsx   # bundle/color/qty form, Add to Cart validation
    AccountView.jsx         # login form (client-side validated)
    CreateAccountView.jsx   # full validated signup form
    CartView.jsx
  utils/
    cart.js               # cart math helpers (subtotal, count, line total)
    images.js             # filename -> bundled asset URL lookup
  assets/images/          # generated placeholder product artwork (SVG)
```

## Running locally

```
npm install
npm run dev       # starts a local dev server (prints the URL)
npm run build     # production build into dist/
npm run preview   # serve the production build locally
```

## Product data and images

Real drawing-tablet listings on Amazon can't be scraped directly (its
robots.txt blocks it), so the catalog in `src/data/products.json` was built
from public research — manufacturer sites and independent buyer's-guide
comparisons of Wacom, Huion, XP-Pen, GAOMON, and Xencelabs tablets — rather
than copied line-by-line from a specific Amazon results page. Model names and
brands are real; exact prices/specs are approximate and meant to be
illustrative for a class project, not live pricing.

27 of the 28 products' `image`/`thumbnail` fields point at real product
photography, hotlinked directly from each manufacturer's own official site
(wacom.com/estore.wacom.com, huion.com, xp-pen.com, gaomon.net,
xencelabs.com) — found by searching each site and pulling the URL straight
out of its product page. One product, the GAOMON **PD1560** (id 25), still uses its generated
placeholder because its official product page renders its photo gallery
entirely in JavaScript, so no static image URL could be extracted. To swap
in a real photo yourself, see the GAOMON PD1560 product page
(https://gaomon.net/products/gaomon-pd1560-pen-display) and paste an image
URL from it into that product's `image`/`thumbnail` fields in
`products.json`.

`src/assets/images/*.svg` are simple, original placeholder graphics
generated by a small script (`gen_catalog.py`, not part of the shipped app)
— a stylized tablet-plus-stylus illustration recolored per product, with a
glowing screen panel for pen displays/standalone tablets vs. a plain matte
surface for screenless pen tablets. Every product still carries one of
these in its `imageFallback` field: `src/utils/images.js` wires an
`onError` handler on every product `<img>` (`ProductCard`,
`ProductDetailView`, `CartItem`) so that if a hotlinked manufacturer photo
ever goes down, gets moved, or is blocked by hotlink protection, the page
swaps to the local placeholder automatically instead of showing a broken
image icon.

To point a product at a different photo (real or placeholder), edit its
`image`/`thumbnail` fields in `products.json` — any `https://` URL is
hotlinked as-is, and any other value is looked up in `src/assets/images/`.
No other code changes are needed.
